A complete verification chain

The project stays deterministic where possible. It records observable facts, verifies atomic claims, reruns declared checks, and emits machine-readable evidence for CI and human review.

Claim → evidence

Completion language is split into independently testable statements and matched to concrete runtime events.

Route attestation

An OpenAI-compatible proxy records requested and returned model identities without retaining prompt or response text.

Project audits

Profiles execute tests, lint, builds, and artifact checks; outputs receive hashes, provenance, SARIF, JUnit, JSON, and HTML reports.

Reproducible replay

Checks can rerun in a clean workspace or resource-limited Docker environment with network disabled by default.

Gaming detection

Detectors cover hidden failures, evaluator tampering, stale artifacts, mock deployments, route substitution, cherry-picking, and leakage.

Privacy-preserving traces

Secrets are redacted, long output is bounded, and transcript content can be represented by cryptographic digests.

Interactive audit

Select a scenario. The same claim receives a different verdict depending on the evidence.

AgentProof verdict

Evidence boundaries are part of the product

0 runtime dependencies

The core package uses the Python standard library. Optional development tools power tests and packaging.

4 verdict levels

Verified, partial, unsupported, and contradicted preserve uncertainty instead of flattening it.

Fail closed by default

Missing evidence, invalid hashes, unexpected exit codes, and mismatched artifacts block strict project profiles.

Scope: AgentProof is application-layer verification infrastructure, not hardware remote attestation, a formal proof system, or a guarantee against every privileged attacker. Benchmark results describe controlled suites and must not be presented as universal real-world detection rates.
